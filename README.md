# RFID & Fingerprint Attendance System

A C++-based attendance system developed using ESP32 and Arduino as part of my Diploma 3 (D3) final project. The system integrates RFID technology, fingerprint recognition, and Wi-Fi connectivity to support user identification and attendance recording through a PHP server.

## Project Overview

This project explores the implementation of embedded systems and hardware integration for attendance management. Using an ESP32 microcontroller, the system processes RFID card data and fingerprint identification, communicates with a backend server, and provides feedback through an LCD display and other hardware components.

## Technologies Used

- C++
- ESP32
- Arduino Framework
- RFID Technology
- Fingerprint Recognition
- Wi-Fi and HTTP Communication
- PHP Backend

## Key Features

- RFID card identification
- Fingerprint-based identification
- Server-based identity verification
- Attendance data transmission
- LCD status display and hardware feedback

## Project Objectives

- Apply C++ programming in embedded systems development.
- Integrate RFID and biometric fingerprint technologies.
- Implement communication between hardware and a backend server.
- Develop a practical attendance management solution.

## Academic Context

Developed as part of my Diploma 3 (D3) final project, this project demonstrates the application of embedded programming, hardware integration, and communication between microcontrollers and web-based services.
